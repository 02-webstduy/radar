# 画像抽取评测（v0）

> 目标不是刷分，是回答一个问题：**AI 从聊天里画出来的画像，靠不靠谱？**
> 运行：`.venv/bin/python scripts/eval_profile.py`（当前模型：本地 Qwen2.5-7B）

## 方法

- 3 段人工构造的对话 + 标准画像（求职 / 读研 / 转岗），每段 5 轮
- 字段：goal / project / stack / learning / hours / interests / avoid / format
- 判定：
  - 完全包含或互相包含 → 对
  - 每个标准词都能在预测里找到 → 对
  - 字符 bigram 重合 ≥ 60% → 对（容忍"求职匹配的项目"这种虚词）
  - hours 只比数字
- 指标：字段准确率、臆造字段数（标准为空但模型填了）

## 结果（2026-11-13）

| 案例 | 正确 | 错误字段 | 臆造 |
|---|---|---|---|
| 求职者 | 7/8 | format 漏了 | 0 |
| 读研/科研 | 6/8 | goal 漏"读研"、project 与学习混淆 | 0 |
| 转岗 | 8/8 | 无 | 0 |
| **合计** | **21/24 = 87.5%** | — | **0** |

## 发现的问题

1. **goal 会只写一半**：用户说"准备读研，想申多模态"，只抽到"多模态方向"。
2. **project 与 learning 容易混**：把"做过 PyTorch 的项目"当项目，漏了"论文复现不太会"。
3. **format 偶发漏**：说了"工程博客、中文"也可能不填。
4. **提示词里的例子会泄漏**：我曾在 prompt 里写"例：读研 + 多模态"，结果模型把"读研"塞进了不相关用户的 goal——已删除所有具体例子。

## 结论

- 7B 能到 **~87%**，但**不能直接信**：必须保留"置信度 + 原话依据 + 用户确认"三件套
- 0 臆造是这套 prompt 的底线；换成更强的 API 模型，先重跑这 3 个案例，再扩到 10–20 个
- 单个案例会抖动（format 时好时坏），所以要看多案例合计，不看单条
